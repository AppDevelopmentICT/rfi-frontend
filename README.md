# RFI / RFP Automation — Frontend

Frontend for the RFI/RFP Automation platform, built with Next.js 16, React 19, Tailwind CSS 4, and shadcn/ui.

## Prerequisites

- Node.js 18+
- npm

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:7777](http://localhost:7777) in your browser.

## Other Commands

| Command | Description |
|---------|-------------|
| `npm run build` | Production build |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |
